# The Bookworm update channel

Automatic-update files for **The Bookworm** are generated by `.github/workflows/build-the-bookworm-wpf.yml`.

The app checks `manifest.json` in this folder. Release payloads and validation metadata are generated from the same compiled executable that is uploaded as the GitHub Actions build artifact.

User books, settings, notes, bookmarks, study guides, questions, and quizzes are stored outside the application-code folder so application updates do not overwrite user data.
