# The Bookworm source

This folder contains the current WPF source bundle for **The Bookworm**.

- `source.zip` is the build source used by the GitHub Actions workflow.
- The app targets .NET 8 / WPF on Windows.
- The app has automatic updates enabled by default and also keeps a manual **Update** action.
- The public update channel lives at `/the-bookworm/` in this repository.

The source bundle contains the green-and-gold fallback cover asset and the current 0.1.0 implementation.
